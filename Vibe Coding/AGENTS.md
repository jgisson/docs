# Agents general Guidelines

- The language is always English. Generate all comments, documentation, commits and code in English.
- The project use AGENTS.md and nested AGENTS.md files to describe agents and code style guidelines.
- Git: Use conventional commit messages for all commits.
- Git: Follow Gitflow branching strategy for all feature development and releases. Use `feature/`, `release/`, `fix/`, `hotfix/`, `docs/` and `chore/` prefixes for branches.
